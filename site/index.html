A crawler that keeps the map.

ReconGraph crawls a site into a graph of what links to what, saves every crawl, and diffs them, so you can see the page that appeared, the endpoint a script started calling, or the new host your checkout page loads.

go install github.com/swapnil5053/recongraph/cmd/recongraph@latest

Or download a binary for Windows, macOS or Linux from releases.

How it's built

Go, one dependency, no cgo, static binaries for five platforms. The decisions, including the ones I reversed, are written up as ADRs.

A pipeline that can't deadlock
Frontier, workers and graph builder form a cycle of bounded channels. The frontier offers its send and receive in one select, so it always drains, and the crawl ends when the queue is empty and nothing is in flight.
One owner for the graph
Only the builder goroutine writes to it, so it needs no locks and scope is enforced in one place.
A lexer for JavaScript
Endpoints come from tokenised scripts, not regex, so comments, escaped slashes and regex literals don't produce false hits.
Tested where it matters
122 tests and a fuzz target under the race detector in CI, heaviest on URL canonicalisation, which the diff depends on.

General notes

  1. No headless browser. A single-page app comes back nearly empty; katana handles those.
  2. JavaScript variables aren't followed, so fetch(base + "/x") isn't resolved.
  3. No passive sources. Nothing from Wayback or certificate logs, only what crawling can reach.
  4. Respects robots.txt and rate-limits per host by default. Only crawl sites you own or are allowed to test.
